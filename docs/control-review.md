# 控件审查与实现进度

本轮审查覆盖 15 个 RP9 文档/元件库的 21 种实际对象类型。包括官方 Default、Flow、Icons、Sample UI Patterns、RP9 Tour，以及校园 App、学生管理、URL Variables、Webstack 和两个 RowClickTable 版本。原始资源不随仓库分发；类型识别、功能实现、浏览器验证与原生截图等价分别记录。

## 已修复

- Webstack 整页原生截图差异：1440×1000 从 10,897 降到 10 像素；1920×3000 从 25,992 降到 20 像素。修复 CSS 矩形圆角、SVG 图片裁剪/描边、Repeater 空图片槽的样式丢失及输入框提示文字偏移。详情见[截图对照](native-comparison.md)。
- `Table` 按 `cells` 的行顺序解析，不使用可能按列排列的 `diagram-objects`；保留独立单元格 ID、文本、事件和边框。`table.rowHeights` / `columnWidths` 驱动布局，修改轨道不会留下过期单元格坐标。
- `TableCell` 支持空文本赋值、点击事件、选中/禁用外观；边框覆盖绘制，不挤压文本，普通相邻 1px 边框不会叠成 2px。输出带 table / row / cell 语义。
- `MenuObject` 展开内部原生表格，恢复静态菜单项和分页按钮。
- `ComboBox` 正确识别，`ListBox` / ComboBox 读取真实 `list-options` 和初始选项；HTML 与 React 保持选项 value / label 的区别。
- 富文本 `AxHyperlink` 内部文字不再丢失。链接专属鼠标/键盘事件已实现，不再触发整段文字的父点击事件。

## 第四批：母版、快照和子菜单

- 母版展开为可编辑控件树，支持嵌套实例、母版自有视图集和页面自适应视图指定的母版视图、文字/图片/嵌套视图覆盖。修复普通分组整理丢弃母版子树的问题。
- 每个实例隔离内部控件、面板状态、SVG 资源 ID、事件目标、单选组和选择组；保留指向实例外部的引用。
- 快照通过独立的静态控件树渲染引用页面/母版，支持背景图片、缩放到适合大小、手动缩放/平移、内边距与裁切；预览动作只修改副本，不运行源页面加载事件，内部控件不可交互。
- 经典子菜单按原生触发单元格关系展开，保留坐标，初始隐藏；鼠标离开时关闭后代菜单。三级菜单遍历/关闭/重新打开均通过 HTML 与 React 测试。
- 新增公开母版/快照/菜单浏览器夹具，并加入 Actions；59 项公开测试 + 41 项研究语料测试通过。真实嵌套母版展开 352 个控件，母版视图样例 7 个控件，三级菜单样例 25 个控件。脚本错误和重复 ID 均为 0；这些新增样例尚无配对原生 HTML，不据此声明像素等价。

新增研究输入来自官方论坛：[嵌套母版与视图](https://forum.axure.com/t/bug-master-views-not-displaying-correctly/56643)、[页面快照](https://forum.axure.com/t/snapshot-cannot-scale-page-background/61491)、[三级菜单](https://forum.axure.com/t/hover-behavior-help/62638)。第三方 RP 和资源仍不分发。

## 第五批：鼠标外观和容器传播

- 普通形状、表单、图片和表格单元格支持 hover / pressed 样式，包含文字、背景、边框和 SVG；按下样式继承悬停覆盖，再应用按下覆盖。
- 选中和禁用外观优先于鼠标外观，移出恢复；输入框切换外观保留实际 DOM 节点和值。
- 组/面板的原生 Propagate 属性控制鼠标外观传播；遇到明确关闭传播的容器停止，不让子控件自己的鼠标事件覆盖父容器正在传播的状态。
- 原创浏览器回归同时验证 HTML/React 的传播边界、移动到兄弟控件、按下/释放、优先级与输入节点稳定性；嵌套母版样例的传播诊断已由实现消除。

## 第六批：面板序列与状态推拉

- 面板支持按表达式返回的状态名称或 1 起始序号切换，名称优先于数字索引，拒绝无效索引。
- 定时重复下一/前一状态、跳过第一次立即切换、循环/非循环终点、设置当前状态停止重复；显式赋值会取消旧序列。重复间隔不短于出入场动画时长。
- 切换自适应大小的状态时按尺寸增量推拉相邻控件；隐藏面板先切换状态，再以新尺寸显示/推开控件。React 使用最新语义尺寸，避免依赖尚未提交的 DOM 尺寸。
- 新增原生动作字段解析测试和 HTML/React 序列浏览器测试，纳入 Actions；公开核心 59 项，本地语料 41 项，共 100 项。

## 第七批：旧数据集快照绑定

- 官方 Default 库中继器的 `repeater-scope` 引用旧数据集快照，但 `Item.Column0` 仍指向当前数据集的稳定列 ID。静态绑定现与表达式路径一致，以稳定列身份解析，恢复三行的 1 / 2 / 3。
- 不按同名列猜测跨数据集绑定；新增合法旧快照与真正外部数据集的正反例测试。Default 库剩余诊断仅为缺失图片资源。

## 富文本与结构检查

- 原生 `RichTextLiteral` 的 `attributed-string-value` 转为可编辑的段落/片段结构；`SetWidgetRichText(..., false)` 已实现，支持混合字体、字号、颜色、粗斜体、装饰、段落对齐/行距和局部/全局/中继器变量。
- 公式跨多个片段时，替换结果继承起始片段的格式；空段落、换行和 HTML 特殊字符保留。相同文字也能改变格式；再次普通赋值保留首片段样式。
- 中继器 ItemLoad 不再将富文本交给静态普通文本绑定器；母版、行实例、批量赋值中的表达式及链接引用独立映射。快照预览支持富文本赋值。
- 修复 HTML 外观切换先恢复旧内容再覆盖富文本、导致链接节点在按下到点击之间被移除的问题。
- 原创富文本浏览器用例覆盖 HTML / React，680×460 整页 RGBA 差异为 0；68 项公开测试 + 41 项本地语料测试通过。
- 另取得两个真实 RP9 文件：[button styling](https://forum.axure.com/t/button-design-icon-and-text-on-button/68105)、[Color Test](https://forum.axure.com/t/unable-to-change-text-color-when-button-clicked/63362)。均零转换诊断，动态赋值与样式在两个渲染器中通过。Color Test 整页差异 0；button styling 的一次捕获有 556 个差异像素，全部落在两处动画 GIF 加载图标，富文本区域无差异。这是两个转换渲染器的比较，尚无这两个文件配对的原生导出 HTML。
- 新增六组[结构用例](structure-review.md)，消除 React 导出中重复的中继器行状态。1000 行用例的 TSX 从 782,498 字节降到 178,001 字节；模板主体不随行数增长。初始选中和禁用状态由运行时构造，并有浏览器回归。

## 可复现检查

```bash
npm run test:tables
npm run audit:controls -- output/control-audit.json project.rp library.rplib
```

审查工具逐文档输出 SHA-256、原生类型数量、转换数量、语义类型和诊断。计数包含非活动面板和每份 Repeater 模板一次，不把展开行数当作独立控件覆盖；嵌套链接、未展开树或母版中的对象可能有不同数量。

表格研究样例来自 [Axure 论坛 RowClickTable](https://forum.axure.com/t/single-row-click-for-table-and-open-details/70428)，原始和扩展版本分别为 66.8 KB / 117.6 KB。尚无同文件原生 HTML 基准，因此表格浏览器回归只证明当前结构、边框和交互实现，不声明像素等价。原生 Table 本身也不提供合并单元格或运行时增删/排序；这些效果通常来自覆盖控件或 Repeater，参见 [Axure Tables 文档](https://docs.axure.com/axure-rp/reference/tables/)。
